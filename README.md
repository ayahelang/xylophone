# Silver Xylophone

Web xylophone ringan berbasis HTML, CSS, JavaScript, dan JSON.

## Fitur
- 8 nada C Major
- Mouse, touch, dan keyboard A S D F G H J K
- Volume dan octave 3–5
- Soft / Bright / Digital tone
- Reverb
- Dark/light mode
- Rekam urutan nada selama sesi
- Responsive & fluid
- Tanpa backend, tanpa build

## GitHub Pages
Upload semua file ke repository GitHub lalu aktifkan **Settings → Pages → Deploy from branch → main/root**.
